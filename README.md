# Multi-Lingual-Voice-Command-System-for-Elderly-Assistance

Traditional voice assistants fail to address the unique requirements of elderly users, particularly
those with:
• Age-related speech characteristics (slower articulation, reduced volume, pitch variability)
• Non-native language proficiency or regional accents
• Cognitive load limitations requiring simplified interaction
• Emergency communication needs requiring prioritized recognition
Existing systems lack specialized adaptations for these populations, resulting in reduced
accessibility, increased frustration, and potential safety risks. This project addresses these
deficiencies by designing, implementing, and evaluating a CNN-based bilingual voice command
recognition system specifically optimized for elderly assistance applications.
1.3 Aims and Objectives
Primary Aim: To develop a robust, bilingual (English-Spanish) voice command recognition
system optimized for elderly users, capable of accurately identifying critical assistance commands
with high reliability.

Datasets Used:

Train: http://download.tensorflow.org/data/speech_commands_v0.02.tar.gz
